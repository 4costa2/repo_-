Bienvenido a ConstruCalc

Una aplicación creada para facilitar la estimación de materiales necesarios en diferentes trabajos de construcción.

A partir de las medidas ingresadas, podrás realizar cálculos de manera rápida y sencilla para obtener una referencia de las cantidades de materiales necesarias.
